Reiniciar o Windows pelo CMD

Reiniciar o Windows pelo prompt de comando é útil quando a interface travou, quando você quer agendar um reinício com aviso, ou quando precisa reiniciar direto no modo de recuperação.

🖥️ Abrindo o CMD como admin

Pressione Win + X → "Terminal (Admin)".

⚡ Comandos essenciais

Reiniciar imediatamente

shutdown /r /t 0

Reiniciar com tempo

shutdown /r /t 60

Reiniciar com mensagem personalizada

shutdown /r /t 120 /c "Salve seu trabalho! Reinício em 2 minutos."

Cancelar reinício

shutdown /a

Reiniciar no modo de recuperação

shutdown /r /o

Desligar em vez de reiniciar

shutdown /s /t 0

⚠️ Importante

  • Precisa do CMD como administrador;
  • O /t aceita valores de 0 a 315360000;
  • Se agendar e fechar o CMD, o reinício continua agendado.

Matar processo travado pelo CMD

Programa travou e não fecha? O comando taskkill mata qualquer processo à força — sem reiniciar o PC.

🎯 Identificando

tasklist

Ou filtre:

tasklist | findstr chrome

💀 Matando por nome

taskkill /IM nome.exe /F

🎯 Matando por PID

taskkill /PID 1234 /F

🌳 Matando processo + filhos

taskkill /IM chrome.exe /F /T

⚠️ Importante

  • /F força — pode perder dados não salvos;
  • Rodar como admin resolve "Acesso negado";
  • Se travar o explorer.exe, o Windows reinicia ele sozinho.

Limpar DNS e resetar a rede

Internet lenta, sites não abrem? Sequência que resolve 90% dos problemas.

🌐 Sequência completa

ipconfig /flushdns
ipconfig /release
ipconfig /renew
netsh winsock reset
netsh int ip reset
ipconfig /registerdns

🚀 Tudo de uma vez

ipconfig /flushdns && ipconfig /release && ipconfig /renew && netsh winsock reset && netsh int ip reset

⚠️ Importante

  • Precisa do CMD como admin;
  • Após winsock/ip reset, reinicie o PC;
  • Se usar VPN/proxy, reconfigurar depois.

Reparar arquivos do sistema (SFC)

Tela azul, travamentos aleatórios? O sfc /scannow escaneia e conserta arquivos corrompidos do Windows.

🛠️ Como usar

sfc /scannow

Pode demorar de 5 a 20 minutos. Não feche.

📊 Resultados possíveis

  • "Não encontrou problema" → sistema ok;
  • "Encontrou e reparou" → reinicie o PC;
  • "Não conseguiu reparar" → rode o DISM antes.

📋 Log detalhado

findstr /c:"[SR]" %windir%\Logs\CBS\CBS.log > %userprofile%\Desktop\sfcdetails.txt

⚠️ Importante

  • Precisa do CMD como admin;
  • Não interrompa o processo;
  • Verifica apenas arquivos do sistema, não programas.

Reparar imagem do Windows (DISM)

O DISM repara a imagem do Windows — complemento ideal do SFC.

🎯 Ordem correta

  1. Roda DISM;
  2. Depois SFC;
  3. Reinicia.

🛠️ Comando principal

DISM /Online /Cleanup-Image /RestoreHealth

⏱️ Demora

10 a 30 minutos. Pode travar em 20% — normal.

📋 Auxiliares

DISM /Online /Cleanup-Image /CheckHealth
DISM /Online /Cleanup-Image /ScanHealth

🔧 Se der erro

DISM /Online /Cleanup-Image /RestoreHealth /Source:D:\sources\install.wim

⚠️ Importante

  • Precisa de internet (a menos que use fonte externa);
  • Erro 0x800f081f → use /Source.

Verificar saúde do HD/SSD

Descubra se seu disco está prestes a morrer.

🩺 Status geral

wmic diskdrive get status

📊 Detalhes

wmic diskdrive get model,size,interfaceType,status

🔍 Erros no sistema de arquivos

chkdsk C: /f /r

/f corrige, /r localiza setores defeituosos.

💾 Vida útil do SSD

wmic /namespace:\\root\wmi path MSStorageDriver_FailurePredictStatus get PredictFailure,Reason

⚠️ Importante

  • chkdsk pode demorar horas;
  • Em SSD use chkdsk C: /f (sem /r);
  • Se retornar "Pred Fail", faça backup urgente.

Reiniciar pendrive pelo Diskpart

CUIDADO: o Diskpart apaga tudo do disco. Errar o número pode formatar seu HD principal.

🛠️ Passo a passo

diskpart
list disk

Identifique pelo tamanho.

select disk 1
clean
create partition primary
select partition 1
format fs=fat32 quick
active
assign
exit

🚀 Versão rápida

format E: /FS:FAT32 /Q /V:PENDRIVE

⚠️ Importante

  • Você vai perder tudo — backup antes;
  • Confira 3x o número do disco;
  • Se ainda falhar, pode estar fisicamente danificado.

Relatório de energia e bateria

Bateria viciada ou consumo alto? O powercfg gera relatório completo.

🔋 Relatório de energia

powercfg /energy

Monitora 60s e gera em C:\Windows\System32\energy-report.html.

🔋 Relatório de bateria

powercfg /batteryreport

⚡ Ver planos de energia

powercfg /list

🔧 Ativar alto desempenho

powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

💤 Ver o que impede dormir

powercfg /requests

⚠️ Importante

  • Precisa do CMD como admin;
  • Não desligue durante os 60s de monitoramento;
  • Capacidade atual baixa = hora de trocar a bateria.

⚠️ Importante

  • Deletar conta pode apagar C:\Users\Usuario;
  • Em inglês, use "Administrators".

Limpeza profunda automática

Temporários, cache e pré-busca acumulam GBs. Esses comandos limpam tudo.

🧹 Temporários do usuário

del /q/f/s %TEMP%\*

🧹 Temporários do Windows

del /q/f/s C:\Windows\Temp\*

🧹 Prefetch

del /q/f/s C:\Windows\Prefetch\*

🧹 Limpeza nativa

cleanmgr /sageset:1
cleanmgr /sagerun:1

🚀 Script .bat

@echo off
echo Limpando...
del /q/f/s %TEMP%\*
del /q/f/s C:\Windows\Temp\*
del /q/f/s C:\Windows\Prefetch\*
echo Limpeza concluida!
pause

⚠️ Importante

  • Alguns arquivos em uso não serão apagados — normal;
  • 1x por mês já é suficiente.

PROCX (XLOOKUP) — Adeus PROCV

O PROCV nasceu ultrapassado. O PROCX faz tudo melhor.

🆚 PROCX vs PROCV

  • Busca em qualquer direção;
  • Não precisa do número da coluna;
  • Não quebra se inserir colunas;
  • Tratamento de erro embutido.

🎯 Sintaxe

=PROCX(valor; matriz_procurada; matriz_retornada; [se_não_encontrado])

💡 Exemplo

=PROCX(A2; Base!A:A; Base!C:C; "Não encontrado")

🔍 Busca da direita pra esquerda

=PROCX(A2; Base!C:C; Base!A:A)

⚠️ Importante

  • Disponível no Excel 365 e 2021;
  • Em versões antigas, use ÍNDICE + CORRESP.

LAMBDA — Crie suas próprias funções

Crie funções personalizadas reutilizáveis sem VBA.

🎯 O que faz

Define parâmetros e uma fórmula. Depois chama como função nativa.

💡 Exemplo

=LAMBDA(valor; valor*1,18)(100)

📌 Registrar como nome

  1. Fórmulas → Gerenciador de Nomes → Novo;
  2. Dê nome (ex: CalcularImposto);
  3. Cole a LAMBDA;
  4. Use =CalcularImposto(A1).

🔥 Combos

=MAP(A2:A100; LAMBDA(x; x*1,18))
=REDUCE(0; A2:A100; LAMBDA(acum; x; acum+x))

⚠️ Importante

  • Apenas Excel 365;
  • Combine com LET pra fórmulas complexas;
  • Impressiona em entrevistas.

Macro de limpeza automática

Uma macro que remove espaços extras, linhas em branco, duplicatas e ajusta colunas.

🛠️ Como criar

  1. Alt + F11 (editor VBA);
  2. Inserir → Módulo;
  3. Cole o código;
  4. Salve como .xlsm;
  5. Alt + F8 → LimpezaProfunda.

💻 Código

Sub LimpezaProfunda()
    Dim ws As Worksheet
    Set ws = ActiveSheet
    Application.ScreenUpdating = False
    ws.UsedRange.Replace What:="  ", Replacement:=" ", LookAt:=xlPart
    Dim i As Long
    For i = ws.UsedRange.Rows.Count To 1 Step -1
        If Application.WorksheetFunction.CountA(ws.Rows(i)) = 0 Then
            ws.Rows(i).Delete
        End If
    Next i
    ws.Range("A1").CurrentRegion.RemoveDuplicates Columns:=1, Header:=xlYes
    ws.Cells.EntireColumn.AutoFit
    ws.Rows(1).HorizontalAlignment = xlCenter
    ws.Rows(1).Font.Bold = True
    Application.ScreenUpdating = True
    MsgBox "Limpeza concluída!", vbInformation
End Sub

⚠️ Importante

  • Salvar como .xlsm;
  • Habilitar macros ao abrir;
  • Teste em cópia antes.
