Reiniciar o Windows pelo CMD

Reiniciar o Windows pelo prompt de comando é útil quando a interface travou, quando você quer agendar um reinício com aviso pros usuários, ou quando precisa reiniciar direto no modo de recuperação.

🖥️ Abrindo o CMD como administrador

Pressione Win + X → escolha "Terminal (Admin)" ou "Prompt de Comando (Admin)". Sem isso, alguns comandos abaixo não funcionam.

⚡ Comandos essenciais

Reiniciar imediatamente

shutdown /r /t 0

Reinicia o PC na hora. O /r significa "restart" e /t 0 é o tempo em segundos (0 = imediato).

Reiniciar com tempo (ex: 1 minuto)

shutdown /r /t 60

Reinicia depois de 60 segundos. Ótimo pra avisar quem estiver usando o PC.

Reiniciar com mensagem personalizada

shutdown /r /t 120 /c "Salve seu trabalho! Reinício em 2 minutos."

O /c permite enviar uma mensagem que aparece na tela.

Cancelar um reinício agendado

shutdown /a

Se você agendou e mudou de ideia, esse comando cancela tudo.

Reiniciar direto no modo de recuperação

shutdown /r /o

Abre o menu avançado de recuperação do Windows após reiniciar. Útil pra resolver problemas sérios.

Desligar em vez de reiniciar

shutdown /s /t 0

O /s significa "shutdown" (desligar). Mesma lógica do /r.

🔍 Verificando o que foi agendado

Não tem como listar diretamente, mas se você esqueceu o tempo, dá pra rodar shutdown /a e depois reexecutar do jeito que quiser.

🔐 Observações importantes

  • Todos esses comandos precisam do CMD como administrador;
  • O /t aceita valores em segundos (0 a 315360000);
  • Se você agendar e fechar o CMD, o reinício continua agendado;
  • Para cancelar, o shutdown /a também precisa ser executado como admin.

Matar processo travado pelo CMD

Programa travou, a janela não fecha, e o Gerenciador de Tarefas não resolve? O comando taskkill mata qualquer processo à força — sem reiniciar o PC.

🎯 Identificando o processo

Primeiro, descubra o nome do processo:

tasklist

Isso lista todos os processos rodando. Se a lista for grande, filtre:

tasklist | findstr chrome

Substitua chrome pelo nome do programa que você quer matar.

💀 Matando por nome

taskkill /IM nome.exe /F

Exemplo pra matar o Chrome travado:

taskkill /IM chrome.exe /F
  • /IM = "Image Name" (nome do processo);
  • /F = "Force" (força o encerramento).

🎯 Matando por PID (número do processo)

Se você sabe o PID (aparece no tasklist ou no Gerenciador de Tarefas):

taskkill /PID 1234 /F

Substitua 1234 pelo PID real.

🌳 Matando processo + filhos

Alguns programas abrem vários processos (navegadores, por exemplo). Pra matar tudo junto:

taskkill /IM chrome.exe /F /T

O /T mata a árvore inteira (processo pai + filhos).

🧠 Matando múltiplos de uma vez

Você pode rodar vários comandos seguidos:

taskkill /IM chrome.exe /F & taskkill /IM firefox.exe /F

Ou salvar num arquivo .bat pra rodar com um clique.

⚠️ Observações importantes

  • O /F força o encerramento — você pode perder dados não salvos;
  • Rodar como admin resolve 99% dos casos de "Acesso negado";
  • Nomes de processos são case-insensitive, mas costumam vir em minúsculas (chrome.exe, explorer.exe);
  • Se travar o explorer.exe (área de trabalho), o Windows reinicia ele sozinho.

Limpar DNS e resetar a rede

Internet lenta, sites não abrem, redes sociais carregam e outras não? Antes de xingar a operadora, roda essa sequência de comandos que resolve 90% dos problemas.

🌐 Sequência completa de reset

1. Limpar o cache de DNS

ipconfig /flushdns

Apaga as informações de DNS guardadas. Ótimo quando um site específico não abre.

2. Liberar o IP atual

ipconfig /release

Devolve o IP que o roteador te deu. Sua internet "cai" por alguns segundos.

3. Renovar o IP

ipconfig /renew

Pede um IP novo pro roteador. Resolve conflitos de IP.

4. Resetar o Winsock (camada de rede)

netsh winsock reset

Reinicia o sistema de sockets do Windows. Resolve problemas causados por VPN, antivírus ou malware.

5. Resetar o TCP/IP

netsh int ip reset

Reseta toda a configuração de IP do Windows pros padrões de fábrica.

6. Registrar DNS novamente

ipconfig /registerdns

Re-registra o DNS do seu computador.

🚀 Rodando tudo de uma vez

Cole isso no CMD como admin:

ipconfig /flushdns && ipconfig /release && ipconfig /renew && netsh winsock reset && netsh int ip reset

Depois reinicie o PC pra garantir que tudo seja aplicado.

🧪 Testando se a rede voltou

ping google.com

Se responder com tempo em ms, tá tudo certo. Se der "host desconhecido", ainda tem problema.

⚠️ Observações importantes

  • Todos os comandos precisam do CMD como administrador;
  • Após o winsock reset e o int ip reset, é recomendável reiniciar o PC;
  • Se você usa VPN ou proxy, pode precisar reconfigurar depois;
  • Em redes corporativas, consulte o TI antes de resetar IP.

Reparar arquivos do sistema (SFC)

Tela azul, travamentos aleatórios, programas que não abrem, erros do Windows Update? O comando sfc /scannow escaneia e conserta arquivos corrompidos do sistema.

🛠️ Como usar

Abra o CMD como administrador e digite:

sfc /scannow

O processo pode demorar de 5 a 20 minutos. Não feche a janela.

📊 Resultados possíveis

  • "Não encontrou nenhum problema" → seu sistema está ok (mas o problema pode estar em outro lugar);
  • "Encontrou e reparou com sucesso" → era isso! Reinicie o PC;
  • "Encontrou problemas mas não conseguiu reparar" → rode o DISM primeiro e depois o SFC de novo.

🚨 Se o SFC não conseguir reparar

Você precisa rodar o DISM antes. Veja a próxima dica (Reparar imagem do Windows).

📋 Log do SFC

Quer ver o relatório completo do que foi encontrado? Rode:

findstr /c:"[SR]" %windir%\Logs\CBS\CBS.log > %userprofile%\Desktop\sfcdetails.txt

Isso cria um arquivo sfcdetails.txt na sua Área de Trabalho com todos os detalhes.

⚠️ Observações importantes

  • Precisa do CMD como administrador;
  • Não interrompa o processo — fechar no meio pode deixar o sistema mais bagunçado;
  • O SFC só verifica arquivos do sistema, não programas instalados;
  • Funciona no Windows 7, 8, 10 e 11 sem alteração.

Reparar imagem do Windows (DISM)

O DISM repara a imagem do Windows (o "molde" do sistema). É o complemento ideal do sfc /scannow — quando o SFC falha em consertar, o DISM prepara o terreno.

🎯 Ordem correta de uso

  1. Primeiro roda o DISM (essa dica);
  2. Depois roda o SFC (dica anterior);
  3. Reinicia o PC.

🛠️ Comando principal

DISM /Online /Cleanup-Image /RestoreHealth

Escaneia a imagem do Windows e baixa arquivos saudáveis direto dos servidores da Microsoft para substituir os corrompidos.

⏱️ Quanto tempo demora?

Entre 10 e 30 minutos, dependendo da sua internet e do estado do sistema. A barra de progresso pode travar em 20% — não cancele, é normal.

📋 Comandos auxiliares

Verificar a saúde da imagem (sem reparar)

DISM /Online /Cleanup-Image /CheckHealth

Rápido, só diz se tem problema ou não.

Escaneamento mais profundo

DISM /Online /Cleanup-Image /ScanHealth

Demora mais, mas detecta problemas menores.

🔧 Se der erro no DISM

Você pode apontar uma fonte externa de arquivos saudáveis (ISO do Windows ou pasta de instalação):

DISM /Online /Cleanup-Image /RestoreHealth /Source:D:\sources\install.wim

Substitua D:\ pelo drive onde está a ISO.

⚠️ Observações importantes

  • Precisa do CMD como administrador;
  • Precisa de internet ativa (a menos que use fonte externa);
  • Não feche a janela durante o processo;
  • Se aparecer erro 0x800f081f, use a opção /Source com a ISO.

Verificar saúde do HD/SSD

Disco rígido morre sem avisar e leva seus dados junto. Com poucos comandos, você descobre se seu HD ou SSD está saudável ou prestes a dar problema.

🩺 Status geral do disco

wmic diskdrive get status

Retorna OK (saudável) ou outro status. Bem simples e direto.

📊 Mais detalhes (modelo, tamanho, interface)

wmic diskdrive get model,size,interfaceType,status

Mostra o modelo do disco, capacidade, tipo (SATA/NVMe) e status.

🔍 Verificar erros no sistema de arquivos

chkdsk C: /f /r
  • /f = corrige erros encontrados;
  • /r = localiza setores defeituosos e recupera informações legíveis.

Atenção: o chkdsk com /f precisa desmontar o volume. Em C:, ele vai perguntar se quer agendar pra próxima reinicialização. Aceite.

💾 Verificar SSD (vida útil)

Pra ver a "vida útil" de um SSD, o melhor comando é:

wmic /namespace:\\root\wmi path MSStorageDriver_FailurePredictStatus get PredictFailure,Reason

Se retornar FALSE, tá tudo certo. Se TRUE, o SSD está avisando que vai falhar em breve.

📈 Relatório completo

Quer um relatório visual completo? Rode:

wmic diskdrive get /format:list > C:\disco.txt

Isso gera um arquivo com todas as informações do disco.

⚠️ Observações importantes

  • O chkdsk pode demorar horas em discos grandes;
  • Em SSDs, use chkdsk C: /f (sem /r) — /r é mais indicado pra HDs mecânicos;
  • Se o disco retornar "Pred Fail", faça backup urgente;
  • Ferramentas gráficas como CrystalDiskInfo são mais amigáveis pro dia a dia.

Reiniciar pendrive pelo Diskpart

Pendrive que o Windows não formata, que perdeu partição, que dá erro "disco protegido contra gravação"... O Diskpart reinicia ele do zero. Comando poderoso — use com atenção.

CUIDADO MÁXIMO: o Diskpart apaga tudo do disco selecionado, sem confirmação. Se você errar o número do disco, pode formatar seu HD principal e perder todos os dados. Confira o disco antes de rodar clean.

🛠️ Passo a passo

1. Abra o Diskpart

diskpart

Precisa do CMD como administrador.

2. Liste os discos

list disk

Aparece algo tipo:

Disco 0    Online      500 GB
Disco 1    Online       16 GB   ← este é o pendrive

Identifique pelo tamanho. Anote o número do pendrive.

3. Selecione o pendrive

select disk 1

Substitua 1 pelo número do seu pendrive. Confira 3 vezes antes de continuar.

4. Apague tudo do pendrive

clean

Isso apaga TODAS as partições do pendrive.

5. Crie uma nova partição primária

create partition primary

6. Selecione a partição recém-criada

select partition 1

7. Formate em FAT32 (ou NTFS)

format fs=fat32 quick

Use fs=ntfs se preferir NTFS (arquivos maiores que 4 GB).

8. Ative a partição

active

9. Atribua uma letra de drive

assign

O Windows atribui uma letra automaticamente (ex: E:).

10. Saia do Diskpart

exit

🚀 Versão rápida (só pra formatar)

Se o pendrive já aparece no Windows, às vezes só isso resolve:

format E: /FS:FAT32 /Q /V:PENDRIVE
  • /FS:FAT32 = sistema de arquivos;
  • /Q = formatação rápida;
  • /V:PENDRIVE = define o rótulo do pendrive.

⚠️ Observações importantes

  • Você vai perder TUDO do pendrive — faça backup antes se tiver dados importantes;
  • Confira 3 vezes o número do disco no list disk;
  • Se o pendrive ainda não funcionar, ele pode estar fisicamente danificado;
  • Pra recuperar dados antes de formatar, ferramentas como Recuva ou PhotoRec ajudam.

Relatório de energia e bateria

Notebook com bateria viciada, consumindo energia demais, ou desligando sozinho? O powercfg gera um relatório HTML completo com tudo que está acontecendo com a energia do seu PC.

🔋 Relatório completo de energia

powercfg /energy

O Windows vai monitorar o PC por 60 segundos e gerar um arquivo HTML em:

C:\Windows\System32\energy-report.html

Abra no navegador. Lá tem: uso de CPU, drivers com problema, dispositivos consumindo energia, erros de configuração.

🔋 Relatório de bateria

powercfg /batteryreport

Gera um HTML em:

C:\Users\SeuUsuario\battery-report.html

Mostra:

  • Capacidade original vs capacidade atual da bateria;
  • Histórico de uso;
  • Tempo estimado de duração;
  • Quantos ciclos de carga já teve.

⚡ Ver planos de energia disponíveis

powercfg /list

Lista os planos (Equilibrado, Alto Desempenho, Economia de Energia).

🔧 Ativar plano de alto desempenho

powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

Esse GUID é do plano "Alto Desempenho". Descubra outros GUIDs com powercfg /list.

💤 Ver o que impede o PC de dormir

powercfg /requests

Mostra programas que estão impedindo o Windows de entrar em suspensão.

🌙 Ver últimos despertares

powercfg /lastwake

Mostra o que acordou o PC da última vez. Útil pra descobrir se algo está reiniciando ele à noite.

⚠️ Observações importantes

  • Todos os comandos precisam do CMD como admin;
  • O relatório de energia monitora por 60 segundos — não desligue o PC nesse tempo;
  • O batteryreport funciona mesmo em desktops (mas mostra "sem bateria");
  • Se a "capacidade atual" estiver muito abaixo da original, é hora de trocar a bateria.

Gerenciar usuários pelo CMD

Criar, listar, alterar senha ou remover contas de usuário no Windows é muito mais rápido pelo CMD do que clicando em menus. Comando base: net user.

👥 Listar todos os usuários

net user

Mostra todas as contas de usuário do computador.

🔍 Ver detalhes de um usuário

net user NomeDoUsuario

Exemplo: net user Misa — mostra nome completo, último logon, status da conta, etc.

➕ Criar um novo usuário

net user NomeDaConta Senha /add

Exemplo: net user Visitante 123456 /add

🔐 Alterar a senha de um usuário

net user NomeDoUsuario NovaSenha

Exemplo: net user Misa NovaSenha123

🚫 Desabilitar uma conta (sem apagar)

net user NomeDoUsuario /active:no

Pra reativar: net user NomeDoUsuario /active:yes

🗑️ Remover um usuário

net user NomeDoUsuario /delete

Atenção: isso remove a conta e os arquivos do usuário. Não dá pra desfazer.

👑 Promover usuário a administrador

net localgroup Administradores NomeDoUsuario /add

Em inglês: net localgroup Administrators NomeDoUsuario /add.

🔽 Remover do grupo de administradores

net localgroup Administradores NomeDoUsuario /delete

📋 Ver grupos do sistema

net localgroup

Lista todos os grupos locais (Administradores, Usuários, Convidados, etc.).

👥 Ver quem está em cada grupo

net localgroup Administradores

⚠️ Observações importantes

  • Precisa do CMD como admin;
  • Em Windows em português, use "Administradores"; em inglês, "Administrators";
  • Criar usuário pelo CMD não cria perfil imediatamente — o perfil nasce no primeiro login;
  • Ao deletar uma conta, os arquivos em C:\Users\NomeDoUsuario também podem ser removidos.

Limpeza profunda automática

Seu Windows pode estar com vários GB de arquivos temporários, cache e pré-busca acumulados. Esses comandos limpam tudo — e você ainda pode criar um .bat pra rodar com um clique.

🧹 Limpar arquivos temporários

del /q/f/s %TEMP%\*

Apaga tudo da pasta %TEMP% (temporários do usuário atual).

🧹 Limpar temporários do Windows

del /q/f/s C:\Windows\Temp\*

Apaga temporários do sistema (precisa de admin).

🧹 Limpar pasta de Pré-Busca (Prefetch)

del /q/f/s C:\Windows\Prefetch\*

Limpa o cache de inicialização de programas. Não faz mal, mas pode deixar o PC mais lento por alguns dias até o cache reconstruir.

🧹 Usar o utilitário nativo de limpeza

cleanmgr /sageset:1

Abre o menu de configuração da Limpeza de Disco. Marque as categorias que quer limpar.

Depois, pra rodar a limpeza configurada:

cleanmgr /sagerun:1

🧹 Limpar cache do Windows Update

net stop wuauserv
del /q/f/s C:\Windows\SoftwareDistribution\Download\*
net start wuauserv

Para o serviço, apaga downloads antigos e reinicia. Ótimo quando o Windows Update está travado.

🚀 Script completo em .bat

Crie um arquivo limpar.bat com este conteúdo:

@echo off
echo Limpando arquivos temporarios...
del /q/f/s %TEMP%\*
del /q/f/s C:\Windows\Temp\*
del /q/f/s C:\Windows\Prefetch\*
echo Limpeza concluida!
pause

Salve como .bat, clique com botão direito → "Executar como administrador".

⚠️ Observações importantes

  • Alguns arquivos podem não ser apagados por estarem em uso — é normal, só ignora;
  • O del /q/f/s apaga sem perguntar — use com cuidado;
  • Não apague manualmente pastas do Windows sem saber o que faz;
  • Rodar limpeza 1x por mês já é mais que suficiente.

Preenchimento Relâmpago (Ctrl + E)

O Excel detecta padrões no que você digita e completa a coluna inteira automaticamente. É como mágica — e economiza horas de trabalho manual.

🎯 Como funciona

  1. Digite 1 ou 2 exemplos do que você quer na primeira célula (e talvez na segunda);
  2. Selecione a célula abaixo da sua coluna;
  3. Pressione Ctrl + E;
  4. O Excel preenche o resto automaticamente.

💡 Exemplos práticos

1. Separar nome completo em nome + sobrenome

Coluna A tem "João Silva", "Maria Santos"... Você digita na coluna B "João" e na C "Silva". O Excel entende e faz o resto.

2. Extrair apenas o primeiro nome

Coluna A tem "João Silva". Você digita "João" na coluna B. `Ctrl+E` completa o resto.

3. Juntar colunas

Coluna A tem "João" e coluna B "Silva". Você digita "João Silva" na coluna C. `Ctrl+E` faz o resto.

4. Formatar telefone

Coluna A tem "11987654321". Você digita "(11) 98765-4321". `Ctrl+E` formata tudo.

5. Extrair partes de e-mails

Coluna A tem "joao@email.com". Você digita "joao" na coluna B. `Ctrl+E` extrai o nome de todos.

🔧 Limitações

  • Funciona melhor com padrões consistentes;
  • Se os dados forem bagunçados, ele pode errar em algumas linhas;
  • Sempre revise o resultado antes de confiar 100%;
  • Disponível no Excel 2013 ou superior.

⚠️ Observações importantes

  • Ctrl + E é o atalho principal;
  • Você também pode ir em Dados → Preenchimento Relâmpago;
  • Funciona em texto, números, datas e misturas.

Atalhos essenciais do Excel

Quem domina atalhos no Excel economiza horas por semana. Aqui vão os 10 mais úteis que ninguém ensina na faculdade.

⚡ Os 10 essenciais

1. Ctrl + T — Transformar em Tabela

Converte o intervalo em tabela estruturada. Filtros automáticos, referências inteligentes, formatação bonita.

2. Ctrl + Shift + L — Filtros

Ativa/desativa filtros na linha de cabeçalho. Rápido e prático.

3. Alt + = — Soma automática

Insere uma fórmula SOMA nas células abaixo ou à direita. Excel adivinha o que você quer somar.

4. F4 — Travar referência

Enquanto edita uma fórmula, pressionar F4 alterna entre $A$1, A$1, $A1 e A1. Essencial pra copiar fórmulas.

5. Ctrl + ; — Data de hoje

Insere a data atual na célula. Ctrl + Shift + ; insere a hora.

Formatação condicional avançada

Vai muito além do "pinta de vermelho se for negativo". Com fórmulas personalizadas, você cria semáforos, heatmaps, barras de progresso e alertas visuais que fazem seu relatório "falar" sozinho.

🎨 Tipos de formatação

1. Semáforo (ícones)

Formatação Condicional → Conjuntos de Ícones. Ideal pra mostrar status (✔ verde, ⚠ amarelo, ✖ vermelho).

2. Barras de dados

Formatação Condicional → Barras de Dados. Mostra visualmente valores maiores/menores.

3. Escala de cores (Heatmap)

Formatação Condicional → Escala de Cores. Valores baixos em uma cor, altos em outra. Perfeito pra matriz de vendas por região.

4. Formatação com fórmula personalizada

Selecionar intervalo → Formatação Condicional → Nova Regra → "Usar fórmula".

=$A1="Atrasado"

Alerta automático de estoque baixo

=$B1<10

Destacar o vendedor do mês

=$C1=MAX($C$1:$C$100)

=MOD(LIN();2)=0

Cria efeito "zebra" nas linhas pares.

=E(HOJE()>=A1-7;HOJE()<=A1)

PROCX (XLOOKUP) — Adeus PROCV

O PROCV (VLOOKUP) foi rei por décadas, mas nasceu ultrapassado. O PROCX (XLOOKUP) faz tudo que ele faz, e melhor: busca em qualquer direção, retorna vários valores, trata erros automaticamente.

🆚 PROCX vs PROCV

  • PROCV só busca da esquerda pra direita. PROCX busca em qualquer direção;
  • PROCV precisa do número da coluna. PROCX usa o intervalo direto;
  • PROCV quebra se você inserir coluna. PROCX não;
  • PROCV exige PROCV+SEERRO. PROCX já tem tratamento de erro embutido.

🎯 Sintaxe do PROCX

=PROCX(valor_procurado; matriz_procurada; matriz_retornada; [se_não_encontrado]; [modo_correspondência]; [modo_pesquisa])

💡 Exemplo prático

Buscar o preço de um produto pelo código:

=PROCX(A2; Base!A:A; Base!C:C; "Não encontrado")
  • A2 = o que você procura;
  • Base!A:A = onde procurar;
  • Base!C:C = o que retornar;
  • "Não encontrado" = o que mostrar se não achar.

🔍 Busca da direita pra esquerda

O que o PROCV nunca conseguiu fazer:

=PROCX(A2; Base!C:C; Base!A:A)

Procura na coluna C e retorna o valor da coluna A.

📦 Retornando vários valores

Retornar nome + preço + estoque de uma vez:

=PROCX(A2; Base!A:A; Base!B:D)

A função "derrama" os 3 valores automaticamente nas células ao lado.

🔎 Busca aproximada

Útil pra faixas (tipo tabela de IR):

=PROCX(A2; Faixas!A:A; Faixas!B:B; "N/A"; -1)

O -1 ativa a busca aproximada (igual PROCV com VERDADEIRO).

🔄 Busca reversa (último item)

=PROCX(A2; Base!A:A; Base!B:B; "N/A"; 0; -1)

O último -1 procura de baixo pra cima — retorna a última ocorrência.

⚠️ Observações importantes

  • Disponível no Excel 365 e Excel 2021;
  • Em versões antigas, use ÍNDICE + CORRESP como alternativa;
  • Funciona em tabelas estruturadas, referências normais e até matrizes;
  • É a função de busca mais poderosa que o Excel já teve.

Matrizes Dinâmicas (FILTRO, ÚNICO, CLASSIFICAR)

Matrizes Dinâmicas são funções que "derramam" resultados automaticamente nas células ao lado. Elas criam listas vivas que se atualizam sozinhas — sem tabela dinâmica, sem macro.

📋 As 3 funções principais

1. ÚNICO — remove duplicatas

=ÚNICO(A2:A100)

Retorna só os valores únicos da coluna A. Se aparecer um novo valor, ele entra automaticamente.

2. CLASSIFICAR — organiza

=CLASSIFICAR(A2:A100)

Coloca em ordem crescente. Pra ordem decrescente:

=CLASSIFICAR(A2:A100; 1; -1)

3. FILTRO — cria relatórios vivos

=FILTRO(A2:C100; B2:B100="SP")

Retorna só as linhas onde a coluna B for "SP". Se os dados mudarem, a lista se atualiza sozinha.

🔥 Combinando as 3 (fórmula campeã)

Lista única + ordenada de todos os estados:

=CLASSIFICAR(ÚNICO(B2:B100))

💡 Exemplos profissionais

Top 5 vendedores

=FILTRO(A2:B100; B2:B100>=MAIOR(B2:B100; 5))

Lista de clientes ativos com filtro duplo

=FILTRO(A2:C100; (B2:B100="Ativo")*(C2:C100>1000))

Contagem dinâmica

=CONT.VALORES(ÚNICO(B2:B100))

⚠️ Observações importantes

  • Disponível no Excel 365 e Excel 2021;
  • As fórmulas derramam — o resultado ocupa várias células automaticamente;
  • Se aparecer #DESPEJAR!, tem algo bloqueando as células de destino;
  • Não funciona em tabelas estruturadas (Ctrl + T) — use intervalos normais.

  • Importa dados de CSV, TXT, Excel, banco de dados, web, SharePoint;

INDIRETO + Referências Estruturadas

O INDIRETO transforma texto em referência real. Isso permite trocar de planilha dinamicamente dentro de uma fórmula, criar modelos de cenário e automatizar relatórios complexos.

🎯 O que INDIRETO faz

=INDIRETO("A1")

Retorna o valor da célula A1, mas o endereço "A1" pode vir de outra célula.

💡 Exemplo 1: trocar de planilha dinamicamente

Digamos que A1 tenha o texto "Janeiro". Você pode fazer:

=INDIRETO(A1 & "!B2")

Isso busca o valor da célula B2 na aba "Janeiro". Se você mudar A1 para "Fevereiro", a fórmula passa a buscar na aba "Fevereiro" automaticamente.

💡 Exemplo 2: somar em várias abas

=SOMA(INDIRETO("'"&A1&"'!B2:B100"))

Soma B2 até B100 da aba cujo nome está em A1. Perfeito pra dashboards multi-mês.

💡 Exemplo 3: busca dinâmica com CORRESP

=ÍNDICE(INDIRETO(A1&"!C:C"); CORRESP(B1; INDIRETO(A1&"!A:A"); 0))

Busca na coluna C da aba especificada, onde o valor da coluna A bate com B1.

💡 Exemplo 4: cenários

Crie um seletor tipo lista suspensa com "Cenário A", "Cenário B", "Cenário C". Depois use:

=INDIRETO("Cenário_"&A1)

⚠️ Limitações importantes

  • INDIRETO só funciona com abas abertas — se a aba estiver fechada, dá erro;
  • Não funciona com Tabelas Estruturadas (referências de tabela) em alguns casos;
  • É volátil: recalcula sempre, pode deixar o Excel lento em arquivos grandes;
  • Cuidado com nomes de abas que tenham espaços ou acentos — precisam de aspas simples.

🚀 Alternativa moderna: DESLOC

Se o objetivo é criar intervalos dinâmicos, DESLOC costuma ser mais rápido que INDIRETO — mas também é volátil.

⚠️ Observações importantes

  • Use com moderação — é uma função poderosa mas "pesada";
  • Ótima pra dashboards executivos com múltiplos cenários;
  • Se ficar lento, considere usar Power Query ou Power Pivot no lugar.

LAMBDA — Crie suas próprias funções

LAMBDA é o recurso mais avançado do Excel moderno. Ele permite criar funções personalizadas reutilizáveis — sem VBA, sem macro, sem sair da planilha.

🎯 O que LAMBDA faz

Você define parâmetros e uma fórmula. Depois pode chamar essa função em qualquer célula, como se fosse nativa do Excel (SOMA, MÉDIA, etc.).

💡 Exemplo simples: calcular imposto

=LAMBDA(valor; valor*1,18)(100)

Define uma função que multiplica o valor por 1,18 (18% de imposto) e já executa com 100. Resultado: 118.

💡 Exemplo prático: função "FormatarCPF"

Se você trabalha muito com CPF, pode criar uma função que formata automaticamente:

=LAMBDA(cpf;
  TEXTO(EXT.TEXTO(cpf;1;3);"000")&"."&
  TEXTO(EXT.TEXTO(cpf;4;3);"000")&"."&
  TEXTO(EXT.TEXTO(cpf;7;3);"000")&"-"&
  TEXTO(EXT.TEXTO(cpf;10;2);"00")
)

Depois é só chamar: =FormatarCPF(A1).

📌 Como registrar como função nomeada

  1. Vá em Fórmulas → Gerenciador de Nomes → Novo;
  2. Dê um nome (ex: CalcularImposto);
  3. Em "Refere-se a", digite sua fórmula LAMBDA;
  4. Pronto — agora CalcularImposto(A1) funciona em qualquer célula.

🔥 Combos poderosos com LAMBDA

MAP — aplicar a função em uma lista

=MAP(A2:A100; LAMBDA(x; x*1,18))

REDUCE — acumular valores

=REDUCE(0; A2:A100; LAMBDA(acum; x; acum+x))

SCAN — acumular mostrando cada passo

=SCAN(0; A2:A100; LAMBDA(acum; x; acum+x))

⚠️ Observações importantes

  • Disponível apenas no Excel 365 (assinatura);
  • Não é uma função comum — é uma linguagem de programação leve dentro do Excel;
  • Combine com LET pra deixar fórmulas complexas mais legíveis;
  • Aprender LAMBDA é o que mais impressiona em entrevistas de emprego hoje em dia.

Macro de limpeza automática

Uma macro simples que faz o trabalho sujo por você: remove espaços extras, linhas em branco, duplicatas, ajusta colunas, converte formatos — tudo em 1 clique.

🛠️ Como criar a macro

  1. Pressione Alt + F11 (abre o editor VBA);
  2. Vá em Inserir → Módulo;
  3. Cole o código abaixo;
  4. Feche o editor e salve como .xlsm;
  5. Execute com Alt + F8 → escolha LimpezaProfunda.

💻 Código completo

Sub LimpezaProfunda()
    Dim ws As Worksheet
    Set ws = ActiveSheet

    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual

    ' 1. Remove espaços extras em todas as células
    ws.UsedRange.Replace What:="  ", Replacement:=" ", LookAt:=xlPart, _
        SearchOrder:=xlByRows, MatchCase:=False, SearchFormat:=False, _
        ReplaceFormat:=False

    ' 2. Remove linhas em branco
    Dim i As Long
    For i = ws.UsedRange.Rows.Count To 1 Step -1
        If Application.WorksheetFunction.CountA(ws.Rows(i)) = 0 Then
            ws.Rows(i).Delete
        End If
    Next i

    ' 3. Remove duplicatas (na coluna A)
    ws.Range("A1").CurrentRegion.RemoveDuplicates Columns:=1, Header:=xlYes

    ' 4. Ajusta largura de todas as colunas
    ws.Cells.EntireColumn.AutoFit

    ' 5. Alinha topo e centraliza cabeçalho
    ws.Rows(1).HorizontalAlignment = xlCenter
    ws.Rows(1).Font.Bold = True

    Application.Calculation = xlCalculationAutomatic
    Application.ScreenUpdating = True

    MsgBox "Limpeza concluída com sucesso!", vbInformation
End Sub

🔍 O que a macro faz

  • Remove espaços extras entre palavras;
  • Apaga linhas em branco automaticamente;
  • Remove duplicatas na coluna A;
  • Ajusta largura das colunas pro conteúdo;
  • Centraliza e negrita o cabeçalho.

🚀 Bônus: criar botão na planilha

  1. Inserir → Formas → escolha um retângulo;
  2. Clique com botão direito → Atribuir Macro;
  3. Escolha LimpezaProfunda;
  4. Pronto — 1 clique faz tudo.

⚠️ Observações importantes

  • O arquivo precisa ser salvo como .xlsm (macro-enabled);
  • Ao abrir, o Excel vai pedir pra habilitar macros — é normal;
  • Teste em uma cópia antes de rodar na planilha real;
  • Você pode adaptar pra incluir suas próprias regras de limpeza.
